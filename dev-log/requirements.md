# 需求文档 · 本地闽菜食材筛选菜谱网站

## 项目概述
构建一个纯前端的闽菜菜谱筛选网站，用户可通过输入或选择食材来查找能制作的闽菜菜谱。

## 功能需求

### F1 · 标题区
- 顶部显示主标题：「闽菜食材菜谱库」
- 副标题：「输入/选择食材，找出能做的菜」
- 显示当前菜谱总数

### F2 · 食材输入区
- **输入框**：可手动输入任意食材名称
- **自动补全**：输入时下拉显示匹配的食材建议
- **添加按钮**：点击或按 Enter 将食材加入筛选条件
- **常用食材标签**：预设 12 个常用食材标签（猪肉、鸡肉、虾仁、香菇、豆腐、芋头、花生、猪脚、鲈鱼、青菜、海蛎、鸡蛋）
- **多选支持**：标签可点击多选/取消
- **已选标签管理**：已选食材以标签形式展示，可单独删除

### F3 · 菜谱展示区
- **默认显示**：未筛选时显示全部 50 道菜
- **实时筛选**：选择食材后立即过滤，匹配规则为——菜谱的 mainIngredients 字段中任一食材与选中食材模糊匹配（双向包含）
- **卡片信息**：菜品名、流派、口味、主要食材（匹配项高亮）、难度、耗时
- **网格布局**：响应式 1/2/3 列布局

### F4 · 菜谱详情弹窗
- 点击卡片弹出详情弹窗
- 显示完整信息：菜名、流派、口味、难度、耗时、主要食材、调料、做法步骤
- 步骤以编号列表展示
- ESC 或点击遮罩关闭

### F5 · 数据来源
- 使用项目文件夹内 recipe.json，包含 50 道闽菜
- 涵盖四大流派：福州菜、闽南菜、闽西菜、莆仙菜

### F6 · 多维筛选（v1.2.0 新增）
- **流派筛选**：全部 / 福州菜 / 闽南菜 / 闽西菜 / 莆仙菜，单选 Chip 按钮
- **难度筛选**：全部 / 简单 / 中等 / 困难，单选 Chip 按钮
- **耗时筛选**：全部 / 快速(≤30min) / 适中(30-60min) / 慢炖(>60min)，基于 parseTimeToMinutes() 自动归类
- **组合逻辑**：四个维度（食材 + 流派 + 难度 + 耗时）AND 组合筛选
- **清除联动**：清除按钮同时重置所有四个维度到默认值

### F7 · 菜谱文化背景（v1.3.0 新增）
- **历史背景**：每道菜新增 `story` 字段，2-4 句介绍创制年代、命名由来、地域关联、文化意义
- **外部链接**：每道菜新增 `link` 字段，指向百度百科词条页面
- **背景展示**：详情弹窗中新增蓝色「📖 文化背景」区块
- **外链按钮**：弹窗底部「🔗 了解更多」按钮，新标签页打开百科页面

## 非功能需求
- 纯前端静态页面，无需后端服务
- 所有代码在单个 HTML 文件中
- 数据以内嵌 JavaScript 数组形式存在
- 响应式设计，支持移动端/平板/桌面
