### v1.0.0 — 初始版本
**日期**：2026-06-09

**概述**：完成本地闽菜食材筛选菜谱网站的初始开发，包含全部功能需求。

**技术细节**：
- 单文件 HTML 应用（index.html），约 500 行代码
- Tailwind CSS v3 CDN + 自定义主题色配置
- 50 道闽菜数据内嵌为 JavaScript 数组
- 12 个预设常用食材标签
- 实时双向模糊匹配筛选
- 详情弹窗展示完整菜谱信息

**文件清单**：
| 文件 | 大小 | 说明 |
|------|------|------|
| index.html | ~25KB | 主应用文件 |
| recipe.json | ~18KB | 原始菜谱数据 |
| dev-log/requirements.md | ~2KB | 需求文档 |
| dev-log/tech-spec.md | ~3KB | 技术规范 |
| dev-log/design-spec.md | ~3KB | 设计规范 |
| dev-log/execution-steps.md | ~2KB | 执行步骤 |
| dev-log/conversation-summary.md | ~3KB | 对话摘要 |
| dev-log/changelog.md | ~3KB | 开发日志（本文件） |

**已知限制**：
- 依赖 CDN（Tailwind CSS、Google Fonts），离线环境需自行引入
- 食材匹配为双向模糊匹配，可能产生非预期结果（如"鸡"会匹配所有含"鸡"字的食材）
- 无 URL 状态持久化（刷新后筛选条件丢失）
- 无打印优化

**后续优化方向**：
- [ ] 添加流派筛选
- [ ] 添加难度/耗时筛选
- [ ] 支持 URL 参数保存筛选状态
- [ ] 支持菜谱收藏功能
- [ ] 添加菜谱搜索（按菜名）
- [ ] PWA 离线支持
- [ ] 打印模式样式优化
