# 闽菜食材菜谱库 · Min Cuisine Recipe Filter

本地闽菜食材筛选菜谱网站——输入你手头的食材，找出能做的闽菜。

## 🚀 快速开始

双击 `index.html` 即可在浏览器中打开，无需安装任何依赖。

## ✨ 功能

- 🔍 **食材筛选**：手动输入或点击常用食材标签，实时匹配可做的菜
- 🏷️ **多维筛选**：按流派（福州/闽南/闽西/莆仙）、难度、耗时组合筛选
- 📋 **菜谱详情**：点击卡片查看完整步骤、调料用量、烹饪贴士
- 📖 **文化背景**：每道菜附历史文化介绍和百度百科链接
- 📱 **响应式布局**：手机/平板/桌面自适应

## 🛠️ 技术栈

HTML5 + Tailwind CSS v3 (CDN) + 原生 JavaScript (ES6+)，纯前端，单文件。

## 📖 使用说明

1. 打开 `index.html`
2. 在输入框输入食材（如「五花肉」），或点击下方常用食材标签
3. 可选：使用流派/难度/耗时筛选器缩小范围
4. 点击菜谱卡片查看详情——用料、步骤、贴士、文化背景
5. 点击「在百度百科查看完整介绍」了解更多

## ❓ 常见问题

| 问题 | 解决 |
|------|------|
| 样式异常 | 检查网络——首次需加载 Tailwind CSS CDN |
| 字体异常 | Google Fonts 可能不可用，浏览器会自动降级 |
| 筛选无结果 | 减少筛选条件，四个维度为 AND 组合 |
